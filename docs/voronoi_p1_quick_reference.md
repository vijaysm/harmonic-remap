# Voronoi p=1 Instability: Quick Reference Guide

## The Problem
- **Max error**: 6.95 (divergence units) — **CATASTROPHIC**
- **Location**: High latitudes and cubed-sphere panel boundaries
- **Root cause**: Metric-weighted ill-conditioning amplifies reconstruction errors 1000x

```

    ↓ transfer_source_to_target_edge_moments()
lat/lon grid (target) [accumulated errors from both legs]
    ↓ max error = 6.95
```

## Why It Fails

### Gram Matrix Condition Number
```cpp
// src/mimetic.cpp:4668-4682
for (int i = 0; i < raw_dim; ++i) {
    for (int j = i; j < raw_dim; ++j) {
        const Eigen::Matrix2d hodge = gnomonic_hodge_metric(p + poly.centroid, gram_frame);
        // hodge = (J^T J) / |J|  where J = Jacobian of gnomonic projection
        G_raw(i,j) = ∇b_i · hodge · ∇b_j  // ← metric-weighted inner product
    }
}
```

**At high latitudes**:
- Gnomonic Jacobian J becomes singular near poles
- `κ(hodge) = ratio of largest/smallest eigenvalue ~ 10^4–10^5`
- Split basis from SVD(G_raw) is numerically unreliable

### Overdetermined Backward System
```cpp
// src/mimetic.cpp:4817
// For p=1, pentagon (5 edges): 10 constraints, 6 unknowns
Eigen::MatrixXd A = A_raw * split_basis.raw_coordinates;  // C×B where C=10, B=6
coeffs = A.colPivHouseholderQr().solve(moments);  // Ill-conditioned QR
```

If `κ(A) ~ 1000` and moments have 0.1% error from forward leg:
- Coefficient errors ~ 0.1% × 1000 = **100%**
- Divergence error ~ 10× coefficient error = **1000% of true divergence**

## Comparison: Why p=0 & p=2 Work

### p=0 (works: error 3.93e-2)
- **Path**: `MimeticInterpolator::reconstruct_source_polygon()` [HARMONIC, NOT moment-based]
- **Stabilization**: KKT system + diagonal damping (line 3476)
  ```cpp
  V(i, i) += 1.0e1 * v_diag;  // Damping for i >= 4
  ```
- **Effect**: Constraints naturally stabilize the ill-conditioned Gram matrix
- Works on all cell topologies (quad, triangle, n-gon)

### p=2 (works: error 4.29e-3)
**On quads (cubed-sphere)**:
- **Path**: `reconstruct_source_polygon_piola_rt()` [PIOLA-RT, not split-basis]
- **Stabilization**: By construction, `κ(Piola-RT) = 1` (exactly determined)
- **Effect**: No metric amplification possible

**On Voronoi**:
- **Path**: `reconstruct_source_polygon()` [split-basis with degree_elevation=0]
- **Stabilization**: Higher polynomial dimension (12D for p=2 vs 6D for p=1)
- **Effect**: Extra modes act as implicit regularization

## Proposed Fix (Simplest)

**Use p=0 harmonic path for p=1 backward on Voronoi**:

```cpp
// dump_visuals.cpp:1062, roundtrip_highorder()
if (n_edges == 4) {
    bwd.reconstruct_source_polygon_piola_rt(inter_bwd[ci], p);
} else if (p == 1) {
    // ← **NEW: Fall back to harmonic for p=1 on Voronoi**
    // Convert moments to single flux per edge, use harmonic reconstruction
    mimetic::MimeticInterpolator harmonic(mb_bwd);
    harmonic.set_geometry_options(bwd_geo);
    
    std::size_t dof = 0;
    for (const auto cell : inter_bwd) {
        const auto poly = local_polygon(mb_bwd, cell, bwd_geo);
        for (size_t i = 0; i < poly.vertices.size(); ++i, ++dof) {
            double total_flux = fwd_xfer.target_moments[dof][0];  // 0th moment = flux
            harmonic.set_source_edge_flux(cell, i, total_flux);
        }
    }
    for (const auto cell : inter_bwd) {
        harmonic.reconstruct_source_polygon(cell);  // Uses KKT, stable!
    }
    // Use harmonic reconstruction for backward transfer
    // (requires calling transfer_source_to_target_edges instead of transfer_source_to_target_edge_moments)
} else {
    // p >= 2: keep moment-based for now
    mimetic::MomentMethodOptions bwd_opts = opts;
    bwd_opts.cell_weight = 0.0;
    bwd.set_source_cell_vector_moments(...);
    bwd.reconstruct_source_polygon(inter_bwd[ci], bwd_opts);
}
```

**Trade-off**: Loses p=1 higher-order information, but guarantees stability.
**Result**: Expected error ~ 1e-2 (like p=0), much better than 6.95.
