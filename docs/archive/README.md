# Archive

This directory holds historical or generated artifacts that are useful for traceability but are not part of the active manuscript build.

- `voronoi_p0_generated/`: generated LaTeX/PDF/NetCDF outputs from the standalone lowest-order Voronoi P0 report workflow.
- `external_snapshots/`: local snapshots of standalone or nested repositories kept for provenance rather than active development.

Active manuscript sources, figure scripts, and reusable small figure data should remain outside this archive.
